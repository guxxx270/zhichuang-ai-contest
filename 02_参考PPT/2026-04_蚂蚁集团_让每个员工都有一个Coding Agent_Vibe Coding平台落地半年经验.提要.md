# 提要｜让每个员工都有一个 Coding Agent：蚂蚁 Vibe Coding 平台落地半年后的实践经验

**来源**：QCon 北京 2026（2026-04）｜彭佩乔（乔杨），蚂蚁集团 支付宝体验技术部 技术专家｜34 页｜原文件名 `彭佩乔-让每个员工都有一个 Coding Agent：蚂蚁 Vibe Coding 平台落地半年后的实践经验 .pdf`（来自 170.zip）
**一句话**：面向全集团非技术员工的"自然语言对话 → 网站/应用"平台（Muse），上线半年 MAU 过万；用三个真实用户故事（PMO、HR、运营）讲遇到的问题和架构升级。

## 结构提纲（6 章）
1. **平台是什么**：四个层次——纯前端展示页 / 前端+接已有后端 / 前后端一体（含数据库 API）/ 智能体应用；所见即所得、可视化编辑、协同分享；一半用户无技术背景，平均 12 轮对话即可发布；2025-07 上线，半年 MAU 过万。
2. **挑战 & 3. 解法（按用户故事）**：
   - PMO 同事 2000 轮对话烧 6 亿 Token 做出生产级战役管理平台 → 问题：Token 消耗快（Prompt 缓存命中率做到 80%）、超长轮次变傻（Memory.md + 语义索引 + 意图保留压缩）、巨型项目卡顿（file graph、上下文主动加载/卸载）、数据库门槛（意图 → DDL/CRUD 自动生成，版本快照回滚）。新架构上线后用户 +109%、活跃 +60%、人均 Token 账单 -23%。
   - HR 同事自建流程管理平台 → AI 听不懂黑话（私有知识 Skills 化）、员工信息不通（预置组件与技能）、敏感数据保障（数据环境隔离、角色权限）、生态割裂（打通内部文档/钉钉/搜索）。
   - 运营同事全程 Vibe Coding 做 C 端营销活动 → 保真还原（多模态 D2C）、客户端适配（预置脚手架 + LLMs.txt 文档库）、高并发性能与自动监控修复。
4. **架构跃迁**：去 Workflow、自主决策、Skills 化；Context 文件即记忆；全局代码索引。
5. **行业趋势**：从"垂类"走向"全能"；一切内容都是文件、一切 Git 管理、一切会话在 WorkTree 中；基础设施的受众从人变成 AI（文档的第一读者是机器，IaC 化、机器可读接口）。
6. **心得**：AI 替代不了真正的程序员，高级程序员价值更高；最近 30 天内部 600 亿 Token、5000 创作者。

## 可借鉴点
- **"人人都有智能体"的另一种解法**：不是每个人配助手，而是让非技术员工自己"说"出工具——这和本赛团队赛口号完全同频，且蚂蚁给了 MAU、Token、创作者数等运营数据，是"可复制推广性"的最佳证据形态。
- **用真实用户故事讲挑战**（PMO / HR / 运营各一个），每个故事 3–4 个 ENCOUNTERED ISSUE + 解法——比罗列技术点生动得多，决赛路演适合这种讲法。
- **敏感数据保障那一页**（环境隔离、角色权限、数据权限）正好对应本赛 15% 的安全合规分。
- **成本页**：Token 账单、缓存命中率——评委会问"贵不贵"，这是回答模板。
- 对我们的"编程提效"场景：个人赛工具赛道可以做一个"业务人员自助生成小工具"的轻量版。
