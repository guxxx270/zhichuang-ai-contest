# 提要｜大模型 Data Agent 重构金融数据价值：从智能分析到决策闭环的范式升级

**来源**：AICon 上海 2025（2025-05）｜岑润哲，数势科技 数据智能产品总经理｜28 页｜原文件名 `AICon_数势科技_岑润哲.pdf`
**一句话**：面向金融机构的智能问数/归因/报告产品 SwiftAgent，核心主张是"指标语义层 + 大模型"让 95% 的业务人员都能用数据（而不是 1% 的决策者和 15% 的分析师）。
**注意**：PDF 水印字符混入正文，文字提取较乱，看原件为准。

## 结构提纲（3 章）
1. **破局时刻**：传统 BI 三大瓶颈（实时决策、语义理解、知识沉淀）；用户原话式痛点——"分析团队像 Excel 的奴隶"、SQL 学习难、BI 报表配置难；数据消费受众从 1%（决策者）→ 15%（+分析师）→ 95%（+业务全员、上下游伙伴）；四层能力金字塔：Ask Data（取数、"快思考"，用 DeepSeek-V3 类模型）→ Data Discovery（同环比、占比、排序）→ Data Reasoning（归因、异常、趋势，"慢思考"，用 R1 类推理模型）→ Data-Driven Action Plan（复盘与建议）；定位从"可视化工具"升级为"业务决策中枢"。
2. **技术攻坚（SwiftAgent）**：五大创新——统一语义层（NL2Semantics 杜绝 SQL 错误）、Human-in-the-Loop（反问与追问）、多源异构数据链接（结构化 + 非结构化 + 企业知识库）、持续反思学习（强化学习学用户提问习惯）、计算加速引擎（OLAP + 虚拟计算）；架构：应用层（智能问数、归因预警、客户画像、财务经营分析、业绩指标分析）→ 规划器（意图识别、任务拆解、工具调用）→ 语义层 → 数据层；已适配国内外多种基座、PC/移动端、文字/语音。
3. **实战与布局**：城商行智能分析场景突破；金融数据智能演进路线。

## 可借鉴点
- **"1% → 15% → 95%"受众扩展图**：一页讲清"可复制推广性"——我们的方案服务的是哪个比例的员工？
- **快思考 / 慢思考分工**（V3 做意图解析、R1 做归因推理）——技术方案里模型选型的合理论证，且显示成本意识。
- **四层能力金字塔**可作为我们"分阶段实施路线"：先取数、再统计、再归因、再建议。
- 与 Shopee、容联云两份对照读：三家都做问数，Shopee 讲工程细节最深、容联云讲行业适配、数势讲产品定位——写方案时三者各取一段。
