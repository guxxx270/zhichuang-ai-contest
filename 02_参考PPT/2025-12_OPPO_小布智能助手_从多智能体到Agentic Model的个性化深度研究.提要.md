# 提要｜从多智能体到 Agentic Model：小布智能助手的个性化深度研究实践

**来源**：AICon 北京 2025（2025-12）｜杨俊，OPPO｜29 页｜原文件名 `杨俊-小布智能助手.pdf`
**一句话**：手机助手里的"深度研究"功能——自动拆解任务、搜集信息、反思修正、生成报告；重点讲三件事：自适应任务规划（简单问题少想、复杂问题多想）、个性化注入与评测、工具扩展到千级。**对应我们"早读 + 追问"技能的方法论。**

## 结构提纲
1. **深度研究是什么**：拆解大纲 → 搜集信息 → 反思修正 / 刷新大纲 → 生成报告；三个技术重点：个性化、自适应规划、工具扩展。
2. **选型思路**：从 Agent 能力构成看（Memory / Tools / Planning）；多智能体（分治，MCP 聚合）vs Agentic Model（在大规模工具环境中训练，工具感知与调度更强）。
3. **自适应任务规划**：目标是帕累托最优——简单问题 Token 少、参数少、步骤少；Context = 引导上下文 + 信息上下文 + 可执行上下文；提示词注入"难易"边界（效果 +4%，耗时 -78%）；Agentic Model 训练（效果 +23%）；"难易"由模型能力与工具范围决定，用多轨迹 rollout 的复杂度与结果多样性来度量。
4. **个性化**：头部产品都做了但缺乏可信的收益衡量；多粒度注入（用户附件 / 知识库）+ 全局使用（任务拆解模块 + 垂域智能体按需检索）；**个性化评测框架**：人工标注 10 分钟级成本高 → 自动化评测，输出稳定性方差 0.0026、换 Judge 模型方差 0.00027；发现"报告丰富度与事实性负相关"；引入个性化后 RACE 分 0.56。
5. **工具扩展**：上下文窗口不足 → 渐进式加载工具定义（MCP 聚合为工具包，先加载名称描述，执行时按需加载完整定义）；工具检索；千级工具冷启动靠 Agentic Data 合成与 DataMix scaling law（论文 arxiv 2510.19336）。

## 可借鉴点
- **早读 = 一次小型深度研究**：拆解（按关注品种）→ 搜集（研报 / 公告）→ 反思（分歧在哪、数据变了什么）→ 生成（5 分钟速读），这页流程图可直接借用。
- **自适应快慢思考**：简单问题（"沪铜涨跌停多少"）走规则 / 小模型，复杂问题（"三家对铜的分歧"）走大模型——技术方案里写上"按难易分流"，既显专业又省 Token。
- **个性化怎么注入**：关注品种、常用口径、周报模板作为"用户知识库"，在任务拆解阶段注入——这就是"人人都有智能体"的技术解释。
- **个性化评测**：我们也要给早读做评测集（研究员盲评"有用 / 无用"），报告"引入个性化后有用率 +X%"。
- **"报告丰富度与事实性负相关"**：早读要克制，宁短勿错——写进设计原则。
