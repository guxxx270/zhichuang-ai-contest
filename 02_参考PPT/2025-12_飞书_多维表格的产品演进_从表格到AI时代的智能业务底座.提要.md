# 提要｜飞书多维表格的产品演进思考：从表格到 AI 时代的智能业务底座

**来源**：AICon 北京 2025（2025-12）｜施凯文，飞书｜36 页（几乎全图）｜原文件名 `1-施凯文-飞书多维表格的产品演进思考：从表格到 AI 时代的智能业务底座.pdf`
**一句话**：多维表格从"表格"长成"业务系统底座"的产品思路——仪表盘 / 透视 / 亿级实时、应用模式"变表格为系统"、"AI 字段捷径"（新建一列即启用 AI：总结、分类、智能回复）、Workflow Agent（自然语言搭自动化流程）、行业方案（物美 AI 智能巡检）。

## 结构提纲（按页图）
1. 关于多维表格：专业 BI 组件、仪表盘、透视表、亿级汇算、实时更新、移动端。
2. 应用模式：变表格为系统；构建足够稳定的专业系统（需求清单 / 设计看板 / 自动提醒的真实案例）。
3. **AI 字段捷径**：新建一列启用 AI——用户评价 → AI 总结 / 舆论分类 / 智能回复，每行自动跑。
4. 行业落地：为物美落地 AI 智能巡检（拍照 → 识别 → 异常提醒）。
5. **Workflow Agent**：用自然语言描述"每天 9 点找出超期未跟进的商机并发飞书消息"，Agent 自动搭出触发 → 检索 → 发送的流程；应用市场模板。

## 可借鉴点
- **"AI 字段捷径"是最轻的 Agent 形态**：投研版——研报清单表新建一列"AI 要点 / AI 立场 / AI 涉及品种"，每行自动填；周报模板里新建一列"本周变化"。如果公司用飞书 / 钉钉，我们的早读结果可以直接落成一张多维表，零开发接入。
- **Workflow Agent 的表达方式**（一句话 → 定时触发 → 检索 → 推送）：早读的"每天 8:30 自动推送给关注该品种的人"就是这种流程，可以画成同样的三步图。
- "变表格为系统"的思路提醒我们：Demo 的账本 / 知识库不一定要自建界面，落到多维表格 / Excel 里研究员更愿意用（可复制推广性）。
