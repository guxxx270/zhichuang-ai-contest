# 提要｜打破"人月神话"，Agent 重塑风控场景产运研职能

**来源**：QCon 北京 2026（2026-04）｜王东旭，快手 磁力引擎风控技术负责人｜49 页｜原文件名 `打破"人月神话"，Agent 重塑风控场景产运研职能-王东旭.pdf`（来自 170.zip）
**一句话**：广告内容审核风控团队如何用 Agent 把"运营提需求 → 产品写 PRD → 研发交付"的固态流水线改成"人人带 Agent"的液态组织，附踩坑与三步演进法。

## 结构提纲（4 章）
1. **AI 时代危机**：审核业务"安全/效率/体验"不可能三角；传统产运研三段式分工的"协调税"；2014→2025 内容安全技术演进；大模型时代线性加人是"人月神话"幻觉；软件 1.0/2.0/3.0 组织形态对比（流水线 → 半人马 → AI 合成旅）。
2. **职能重塑之路**：产运研 Agent 协作全景图（产品层：原型/需求/PRD 评审 Agent；研发层：需求理解/编码测试/运维发布 Agent；运营层：Prompt 运营 / RAG 运营 / Agent 运营）。产品经理 → "P2P（Prompt to Product）"；策略运营升级为 PE 运营（写审核 Prompt，含角色/流程/注意事项/核心判断点/豁免场景/回复格式模板）、RAG 运营（风险案例资产化、多路召回重排）、Agent 运营（APE 自动提示词优化、AML 自动挖掘标注）；研发按需求颗粒度选协作模式（小：终端对话 / 中：Rules+Skills / 大：Spec Coding）；Prompt Engineer → Context Engineer → Harness Engineer；MLLM-as-Judge 质量左移；算法向下深耕垂类 MLLM（KwaiBLM，预训练/中训练/后训练，30B-A3B 成本降 80%）。
3. **坑点和教训**：技术坑（存量 Repo 反向构建 Context、语义索引、补测试围栏、AI-friendly 重构）；管理坑（追求面面俱到引发新老冲突 → 灰度试错 / 双轨并行 / 价值重估三步）。
4. **组织行动建议**：绩效从"研发吞吐量"转向"AI 杠杆率 / Token ROI / Skills 贡献"；逆康威定律先重构组织；先立标杆（10x 超级个体）→ 打破部门墙（Micro Superteam）→ 统一内部基建（防 Shadow AI）。

## 可借鉴点
- **叙事线极好用**："业务不可能三角 → 协调税 → 人月神话失效 → 用 Agent 重塑角色 → 踩坑 → 行动建议"，是一条完整的"痛点-方案-成效-复制"路径，直接对应本赛评分四个维度。
- **"人人都有智能体"的具体形态**：不是给每人一个聊天框，而是按角色定义 Agent（运营写 Prompt、研发用 Coding Agent、产品用 P2P），可以照搬到期货公司的"研究员/交易/合规/客服/IT"角色矩阵。
- **审核 Prompt 模板**（角色定义 / 审核流程 / 注意事项与限制 / 核心判断点 / 豁免场景 / 回复格式 `<think>` `<answer>`）——个人赛"技能赛道"评分要求"角色/约束/输出规范明确、泛化强、易复用"，这页就是范本。
- **需求颗粒度 × 协作模式矩阵**（小/中/大 → Chat / Skills / Spec）——"编程提效"场景的方案页可直接套。
- **Harness = 马具**的比喻：Prompt 决定上限、工程约束守住底线——讲"技术与落地可行性"和"安全合规"时的一句话金句。
- **AI 杠杆率 / Token ROI** 作为成效指标——比"节省 N 人天"更有新意，可用在"业务价值与成效"页。
