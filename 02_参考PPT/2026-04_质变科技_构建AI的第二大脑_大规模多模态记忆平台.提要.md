# 提要｜构建 AI 的"第二大脑"：大规模多模态记忆平台技术实践

**来源**：QCon 北京 2026（2026-04）｜周祥，质变科技（MemoryLake）｜35 页（图为主）｜原文件名 `周祥-构建 AI 的"第二大脑"：大规模多模态记忆平台技术实践.pdf`
**一句话**：厂商视角讲"企业 AI 落地的失忆困境"——AI 每次醒来都是一张白纸，第 3 周重复上周已纠正的错误、第 5 周在董事会引用已被否定的数据、第 7 周项目暂停；解法是把 PDF / Excel / PPT / 会议录音 / 聊天记录统一表征进"记忆平台"，多路检索 + 多跳推理 + 记忆分层。

## 结构提纲
1. **失忆困境**：一条时间线讲清"不是 AI 不够聪明，而是它每次醒来都是白纸"；LLM 是第一大脑、记忆平台是第二大脑（Gartner：AI Memory 市场 2028 年 $28B）；单机 / 大数据 / AI 三个时代的基础设施类比（Agents/Skills → Memory → Tools/API → LLM(OS)）。
2. **突破 1 多模态统一表征**：Excel（文件类型识别 → 多表识别 → 转置识别 → 格式识别 → 数据提取 → 增强 → 索引）、PDF（版式识别 → 文字 / 图像 / 表格 / 公式 → 跨页合并 → 语义索引），Skills Center 全流程可自定义；TableBench / DABStep 榜首。
3. **核心技术 3 亚秒级多跳推理**：QueryAgent——查询理解（指代消解 / 上下文补全）→ 多路检索（关键词 + 向量 + 图谱）→ 多跳推理（平均 3 跳）→ 增广预提问 → Self-consistency 验证 → 带溯源标注回答；LoCoMo 94.0% 超人类标注 87.9%。
4. **痛点 2 检索成本失控**：10 万亿级记录纯向量检索超时；解法：混合检索 + 记忆分层（热 / 温 / 冷）+ 渐进压缩（冷记忆不删而是压缩）+ 查询路由；<200ms、95%+ 精度、成本 30×。
5. **Skills 开放网络**：领域知识注入（金融等 10PB+）、业务知识注入（元数据 / 术语映射 / 计算指标 / 业务规则 / 示例问题库）；一键搜索全球高质量数据集（含 FRED / SEC 文件 / 金融实时数据）。
6. **结论**：记忆是从 Demo 到生产的关键缺层；记忆 ≠ 存储，记忆是活的（理解、组织、压缩、遗忘、演进）；生产级门槛：多模态精准理解、超大规模低成本检索、可解释可干预。

## 可借鉴点
- **"失忆困境"时间线**是讲"为什么要有个人记忆 / 关注画像"最生动的开场，改成"研究员版"：第 1 周问什么答什么、第 3 周又把上月已修正的口径拿出来、第 5 周周报引了过期数据……
- **"记忆 ≠ 存储，记忆是活的"**：给"早读会遗忘过期观点、更新变化数据"一个理论表述。
- **多跳推理 + 溯源标注**：百事通回答规则问题必须带条款出处，这页给了工程形态。
- 金融数据集（FRED / SEC）与"业务知识注入"（术语映射、计算指标、业务规则、示例问题库）——百事通的知识库结构可以照此分层。
