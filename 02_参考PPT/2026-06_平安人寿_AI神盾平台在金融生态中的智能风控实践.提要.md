# 提要｜AI 神盾平台在金融生态中的智能风控实践

**来源**：AICon 上海 2026（2026-06）｜黄佳豪，平安人寿 金管家基础平台研发组副经理｜32 页｜原文件名 `AI 神盾平台在金融生态中的智能风控实践.pdf`
**一句话**：保险公司 App 的活动/权益/资金风控中台，从规则引擎演进到"AI 巡检智能体"（多 Agent 根因分析），覆盖 152 个场景，根因准确率 85%+、处理周期缩短 50%。

## 结构提纲（5 章）
1. **风控系统演进**：开场用一个真实资损案例（营销活动奖品发放漏洞被羊毛党扩散、阻断失败、只能回滚）；风控四阶段（传统 → 数字化 → 大数据 → 智能，2022 至今 AI 深度融合）；平台自身演进（规则引擎 → 数据建模 → 告警体系 → 神盾中台 → 风控智能体）；行业现状对比表（头部 vs 中小机构：架构/记忆/模型/多模态）；行业基准数字（拦截率 72%、高价值欺诈率 2%、MTTR 15min）；三大痛点：烟囱式架构、外部风险升级（深度伪造、黑产）、内控能力缺失。
2. **AI 神盾平台架构**：四维价值（广度 152 场景、精度 阻断效率 +42%、速度 秒级告警、深度 事前策略编排/事中原子级熔断/事后对账；问题发现精确度 +50%、解决效率 85%）；告警指标体系（系统指标 + 业务指标）；五大垂域功能矩阵（资金/营销/账户/内容/业务风控）× 五层（接入 → 数据处理 → 智能分析 → 决策执行 → 运营治理）；三大引擎（规则 / 数据 / AI，含 Agent Tools、Memory、MCP/Skill）；全链路：采集 → 分析 → 分级告警 → 自动熔断 → 工单闭环。
3. **AI 巡检智能体**：Agent + Workflow 协同；信息采集 Agent → 根因分析 Agent / 关联分析 Agent / 影响评估 Agent → 分级评估 → 触达（IM 对话、巡检报告、消息通知）；知识库：历史告警、案例库、SOP、故障模式库。
4. **场景深度实践**、5. **未来展望**。

## 可借鉴点
- **开场讲一个"没有它就会资损"的真实故事**——比讲技术先讲损失，评委立刻明白价值；期货公司同样可以从一次风控/合规事件切入。
- **"四维价值"页**（广度/精度/速度/深度各配一个数字）是"业务价值与成效"页的极佳版式。
- **行业对比表**（头部 vs 中小 vs 行业基准）把自己放在行业坐标里，显得有格局，决赛面对高管很有用。
- **多 Agent 分工（采集/根因/关联/影响）+ 知识库（SOP、案例、故障模式）**是"投研风控"场景的标准架构，可直接改造为交易异常巡检、客户异常行为巡检。
- 熔断（活动/发放/支付）= "AI 建议、系统执行、人可介入"的安全叙事。
