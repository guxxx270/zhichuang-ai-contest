# 提要｜小布记忆：全模态碎片化内容的理解与智能整理实践

**来源**：AICon 上海 2026（2026-06）｜王闯闯，OPPO 高级算法工程师｜32 页（图为主）｜原文件名 `小布记忆：全模态碎片化内容的理解与智能整理实践.pdf`
**一句话**：手机上的"记忆"App——截图、语音、视频、文档、多图这些碎片"一键闪记"，端侧多模态模型理解成结构化记忆单元，RL 智能体负责整理（遗忘 / 更新 / 去重 / 合并），长期用户画像驱动主动服务。**"记 - 管 - 用"三段与 L0～L3 记忆分层，是个人信息整理类 Agent 的标准架构。**

## 结构提纲
1. **问题与背景**：用户每天产生大量碎片（截图 / 语音 / 视频 / 文档 / 多图，如行程订单、会议记录、合同批量参数）；传统方式失效：需要回看时"记不起来、找不到、整理不动"，靠人工分类"最大重复易遗漏"，靠关键词搜索"跨模态难以串联"。结论：AI 若不能"理解 + 关联 + 整理"，记忆就只是数据堆积。
2. **整体架构：记 - 管 - 用 + 记忆分层 L0～L3**：L0 原始碎片 → L1 结构化记忆单元（端侧 AndesVL 多模态理解、OCR/ASR/文档解析、实体对齐）→ L2 合集 / 主题记忆（RL 记忆管理 + Agentic RAG）→ L3 长期用户画像（主动服务）。
3. **记**：多入口接入（魔方键、三指上滑、截屏、CUI）统一记忆出口；端云协同，端侧引擎自研 AndesVL，端云任务分流。
4. **管**：记忆管理三阶段——只记不管（冗余、冲突堆积）→ 固定规则（多实体场景失效）→ **RL 记忆管理智能体**（以记忆效用为奖励，GRPO 学习何时调用检索 / 写入 / 更新 / 去重 / 合并 / 删除遗忘）；关联与归纳：Agentic RAG / plan-execute（多策略检索 + 重排 + 校验 LLM 按需）；合集应用 Agent。
5. **用**：L3 长期画像与记忆消费闭环（主动服务、个性化推荐、行程 / 生活助手），反馈回流"管"形成自进化。
6. **工程实践**：流程化算法开发 + 自动化评测（LLM-as-a-Judge + Badcase 闭环）。效果：L1 记忆生成精度 ≥ 92%，function call 准确率 95%、记忆碎片召回率 97%、去重 / 更新准确率 90%、L3 记忆带来用户点赞提升 +11%。

## 可借鉴点
- **"记 - 管 - 用"三段论**可以平移为投研版本："读（研报 / 公告 / 纪要碎片）- 管（按品种 / 主题归并、去重、更新、遗忘过期观点）- 用（早读、追问、写周报）"。
- **L0～L3 分层**：L0 原始材料 → L1 要点卡 → L2 品种 / 主题合集 → L3 个人关注画像——一页图讲清"个性化"是怎么来的。
- **记忆管理从"只记不管"到"固定规则"再到"智能体"的三阶段**：论证为什么简单的文件夹 + 关键词搜索不够。
- **效果指标写法**：一组精度 / 召回 / 准确率 + 一个用户侧指标（点赞 +11%）。
- 端侧执行、数据不出手机——对应我们"数据不出域"。
