# 提要｜蚂蚁集团 CIO 智能转型助力业务提效的实践

**来源**：AICon 上海 2025（2025-05）｜杨浩（冀恒），蚂蚁集团｜26 页（图为主）｜原文件名 `蚂蚁集团CIO智能转型助力业务提效的实践-杨浩.pdf`
**一句话**：以财务条线为例讲企业内部办公 AI 的落地范式——三种应用模式（AI Embedded / Copilot / Native）、按子域划分"财务数字员工"、两个实践（智能审核、自然语言取数）、以及"搭组织"的方法。**内部办公智能体如何从 Copilot 走到"数字员工"的组织级范本。**

## 结构提纲
1. **"AI + 财务"新阶段**：智能财务成熟度 L1–L4；三种范式——AI Embedded（结算核销规则推荐、智能核算方案生成、波动归因）、AI Copilot（采购智审插件、报表分析助手、账单查询助手、税务助手）、AI Native（按子域划分财会 / 管会 / 司库三大数字员工）。架构分层：交互层 LUI → 数字员工运营 → 数据工程 / 知识工程 / 多智能体 → 基础设施与模型治理。
2. **实践 1 财务智能审核**：基于 LLM 构建"感知 - 决策 - 执行 - 反馈"闭环，结构化采集 + 动态清洗 / 学习 / 评测 + 灰度上线，重点审核场景准确率 99.9%，系统决策成功率 90%+；分阶段治理："辅助审核 → 半自动审核 → 无人值守审核"，每阶段有准确率门槛与人工介入比例。
3. **实践 2 财务智能分析（自然语言取数）**："帮我查集团 2024 年 3 月各天营业收入并画折线图" → 意图识别（小模型）→ 参数提取 → NL2DSL（模糊 DSL → 向量检索 / 模糊匹配 / 二次确认 → 精确 DSL）→ 执行展示。
4. **总结：LLM 应用范式 - 搭组织**："财务数字员工"执行委员会：纵向按域主建（核算 / 结算 / 税务 / 管会 / 司库），横向按能力（交互层、AI Native 基础架构 Agent/RAG/知识库、模型算法）；口号"以 AI 力为核心引擎，重构企业智能办公生产力新范式"。

## 可借鉴点
- **Embedded / Copilot / Native 三种模式**：一页讲清我们的"投研伙伴"处于哪一档、往哪一档演进——决赛面对高管很好用。
- **"辅助 → 半自动 → 无人值守"三阶段 + 每阶段准确率门槛**：安全合规与可靠性的叙事模板（早读先"辅助"，人工确认后才"半自动"推送）。
- **NL2DSL 的"模糊 → 二次确认 → 精确"**：百事通做规则计算时同样要"先确认口径再算"。
- **搭组织那页**：纵向按业务域（投资 / 资管 / 研究）、横向按能力（交互 / Agent 基础 / 模型）——正好是我们 5 人分工的画法，也回应"可复制推广性"。
