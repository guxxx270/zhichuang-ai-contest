# 提要｜智能体驱动信贷风险的动态感知到策略自迭代

**来源**：AICon 深圳 2025（2025-08）｜董纪伟，同盾科技 副总裁｜45 页｜原文件名 `董纪伟-智能体驱动信贷风险的动态感知到策略自迭代.pdf`
**一句话**：风控厂商讲"静态策略 vs 动态因子"的核心矛盾，提出大模型驱动的风控自进化闭环（态势感知 → 策略热生成 → 沙盒验证 → 人机协同运营），配套风控 MCP 工具集与领域 Agent 集市。

## 结构提纲（5 章）
1. **公司简介**：决策智能操作系统"智策 2.0"（场景 Agent + 算力引擎 + 数据要素）；风控大模型训练语料 1500 亿 Token（上万风险策略、百万级特征）；风控 MCP 工具集与智能体集市（欺诈侦测 / 智能报告 / 案例查证 / 授信评估 / 特征挖掘 / 多模态画像 Agent）；知识库（向量 RAG + GraphRAG）；大小模型决策融合；多基座接入。
2. **信贷风控的敏捷性困局**：四大困局——数据割裂黑洞（60% 风险因数据孤岛漏判）、模型失灵（传统模型误判率 >30%、辛普森悖论）、被动风控"死亡空窗期"（政策时差、脚本化攻击）、"乱枪打鸟"（规则上千不敢删）。核心矛盾：静态策略 vs 动态因子——政策新规（八百里加急）、突发异变、行业骤变（灰犀牛）、经济波动。软策略示例：动态阈值（旺季拒后 8%、淡季拒后 3%）。
3. **自进化闭环框架**：态势实时感知（多维监控、异常第一手分析）→ 策略热生成（大模型工具把挖掘优化方法标准化）→ 沙盒对比验证（全方位验证后才上线）→ 人机协同运营（冲突反馈与人工审批）。
4. **场景实践**、5. **总结展望**。

## 可借鉴点
- **"静态策略 vs 动态因子"的矛盾框架**可平移到期货风控：保证金/持仓限额/异常交易规则同样是静态的，而行情、政策、客户行为是动态的——这是"投研风控"场景一个很好的选题切口。
- **闭环四步（感知 → 生成 → 沙盒 → 人审）**是"AI 不直接上线、必须沙盒验证 + 人工审批"的安全叙事，既拿创新分也拿合规分。
- **痛点数字化**（60% 漏判、>30% 误判）——即使是厂商口径，也说明评委吃这一套。
- **风控 MCP 工具集 + Agent 集市**：对应"人人都有智能体"里的"能力复用"，可作为可复制推广性的论据。
