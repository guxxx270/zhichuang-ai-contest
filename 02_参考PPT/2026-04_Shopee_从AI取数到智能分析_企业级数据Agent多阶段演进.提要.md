# 提要｜从 AI 取数到智能分析：企业级数据 Agent 的多阶段演进与工程化落地

**来源**：QCon 北京 2026（2026-04）｜王新波，Shopee Data Infra｜30 页｜原文件名 `王新波-从 AI 取数到智能分析：企业级数据-Agent 的多阶段演进与工程化落地.pdf`（来自 170.zip）
**一句话**：一个"自然语言问数"产品从 RAG+Text2SQL 第一版（真实数据准确率 39%）到 Multi-Agent + 语义模型 + Skill 的五次跃迁，重点是让 Agent 在生产环境可靠运行的工程体系。

## 结构提纲（5 章）
1. **背景与挑战**：BI 四阶段（静态报表 → 自助 BI，仅 8% 用户会编辑 → 增强分析 → AI 原生 Agent）；第一版架构（Embedding 检索表 → 拼 Prompt → 生成 SQL）在学术集 85–91%、真实企业数据只有 39%；五大问题：找表不准、语义错、语法错、体验割裂、评测缺失。
2. **Text2SQL 演进**：五次跃迁——Multi-Agent（Supervisor + 业务域定位 / 找表 / 生成 SQL 三个子 Agent + Human-in-the-Loop）、元数据渐进式披露（百万表 → 域内数百 → 候选数张 → 完整字段）、四层知识体系（文档层 / 业务层 / 基础层 / 样例层）、双层个性化（静态画像 + 动态记忆）、语义模型（业务术语 → 指标/维度定义 → 屏蔽 Join/分区，Text-to-DSL）、AI 辅助语义建模 + 专家审核的正向循环。
3. **工程体系**：技术底座（FileSystem-as-Context、Sandbox、工具箱、Skills、Memory）、评测体系（LLM 生成问题 + 执行比对 + 人工 Review）、运营体系（反馈采集、知识优化、线上采纳率）；元数据治理：AI 批量生成表描述 + 业务方 Review + 血缘扩散（人工治理 2000 张 → 扩散 15 万张，描述采纳率 70%，治理时间 30min → 10min，找表精度 +15pp）。
4. **Skill 场景化分析**：把专家分析经验（归因分析五步：指标下钻 → 维度拆解 → 变化因子 → 根因排序 → 结论）沉淀为可复用 Skill，Agent 在沙箱逐步执行。
5. **总结展望**。

## 可借鉴点
- **"问数"是期货公司最容易讲清业务价值的场景之一**（经营分析、客户分析、保证金/持仓监控），这份 PPT 给了从 0 到生产的完整路线，且诚实地给了"39% 起步"的数字——评委爱看真实数字。
- **Human-in-the-Loop 分层确认**（确认业务域 → 确认候选表）是"安全合规"和"可靠性"的好话术：AI 不直接出结果，人在关键节点纠偏。
- **语义模型/指标口径前置**：金融公司数据口径极其敏感（"活跃客户""权益"怎么定义），这页论证了为什么不能裸 Text2SQL——方案里写上会显得懂行。
- **元数据治理成效页**的写法（4 个数字 + 一句结论）是"业务价值与成效"页的模板。
- **Skill 化专家经验**（归因分析五步）——研究员/风控的分析套路同样可以 Skill 化，且对应个人赛"技能赛道"。
