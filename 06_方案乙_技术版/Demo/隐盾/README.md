# 隐盾 · 贴给大模型前先脱敏（个人赛 · 工具赛道）

> 任何文本贴进去，手机号 / 资金账号 / 证件号 / 邮箱 / 内网地址 / 密钥 / 大额金额 / 客户与机构名 自动换成带类型的语义标签；拿到大模型回答后一键还原。纯本地规则，不联网、不装模型、即插即用。

## 为什么

大赛红线："未脱敏的客户身份信息、交易持仓数据、内部财务数据不得上传至未经许可的公网大模型"。员工日常用 AI 最容易踩的就是这一步——把微信原话、邮件、工单直接贴过去。隐盾让"贴之前先过一道门"变成 3 秒钟的习惯。

## 用法

- 网页：双击 `启动隐盾.command`（Mac）或 `streamlit run app.py`。左边贴原文 → 脱敏 → 复制去问 AI → 把回答贴回 ② → 还原。侧边栏可加自定义客户 / 机构名单。
- 命令行：`python cli.py redact 文件.txt`（映射表写到 `文件.map.json`）；`python cli.py restore 回答.txt 文件.map.json`。
- 嵌入：`from yindun.privacy import Redactor`，两个方法 `redact()` / `restore()`，已在团队作品「研伴」「需知」中作为安全模块复用。

## 规则清单

| 类型 | 识别方式 | 示例 → 标签 |
|---|---|---|
| 手机 | 1 开头 11 位 | 13912345678 → 〈手机_1〉 |
| 资金账号 / 银行卡 | 10～19 位数字 | 8812345678901 → 〈账号_1〉 |
| 身份证 | 18 位含出生日期校验 | → 〈身份证_1〉 |
| 邮箱 | 标准邮箱格式 | → 〈邮箱_1〉 |
| 内网地址 | 10.x / 192.168.x / 172.16～31.x | 192.168.10.21 → 〈内网地址_1〉 |
| 密钥 | api_key / token / secret / password / 密码 = … | → 〈密钥_1〉 |
| 大额金额 | 带千分位的金额 | 1,250,000 元 → 〈金额_1〉 |
| 客户姓名 | "客户 / 投资者 + 姓名"、"姓 + 先生 / 女士"（常见姓氏表） | 客户王建国先生 → 客户〈客户_1〉先生 |
| 机构名 | "客户 / 机构 + XX公司 / 集团 / 基金 / 资管 / 投资 / 私募 / 厂" | → 〈机构_1〉 |
| 自定义 | 侧边栏名单（词典脱敏） | 任意 |

设计要点（对照腾讯玄武"隐私不上云"的能力框架）：语义保持（标签带类型，模型仍知道这是个客户、这是个手机号）；信息还原（同一实体全文同一标签，多轮一致，`restore()` 原样还原）；开集指定（自定义名单）；端侧执行（纯规则，不依赖网络）。

## 测试

`pytest -q tests`：七类实体逐一命中并可还原；同一客户多次出现映射一致；自定义名单生效；角色词（客户经理）、日期、合约代码不误伤。

## 已知边界

- 姓名识别依赖上下文（"客户 / 投资者"前缀或"先生 / 女士"后缀），无上下文的裸姓名请用自定义名单。
- 不识别持仓明细表格里的数字——那类数据本就不该贴给公网模型，工具的定位是"贴之前过一道门"，不是替你把持仓表脱敏后再上传。
