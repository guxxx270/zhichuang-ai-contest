# 「问清」需求追问提示词（个人赛 · 技能赛道）

- `问清_提示词_v1.md`：完整提示词（角色 / 约束 A 读法 / 约束 B 期货行业追问规则 24 条 / 约束 C 通用检查项 12 条 / 输出规范 JSON），复制即用。
- `示例_3组.md`：三组输入（微信 / 纪要 / 邮件原话）与参考输出（结构、粒度、语气的标准）。
- `稳定性测试.py`：对三组样例各跑 N 次，统计 JSON 可解析率、标题一致率、问题集合重叠度、用时，生成 `稳定性测试_报告.md`（评审"泛化能力强、换参数稳定"的证据）。在需知目录配好 `.env` 后运行：`python 稳定性测试.py 3`。

评审维度对照：结构清晰（角色 / 约束 / 输出规范三段式，字段名固定）；泛化能力（三种来源的原话、不同长度、不同部门均稳定输出，测试报告为证）；易复用（改约束 B 即可迁移到其他行业；输出 JSON 可被任何系统消费）。
来源：团队作品「需知」的问清技能（`prompts/intake_refine.md` + `knowledge/futures_probes.json`），联动申报。
