一个"我"
关注品种、角色、周期、模板、反馈——同一批材料，每人一份不同的晨读。个性化只在画像层。
四项技能
每项技能 = 规范（Prompt）+ 代码（规则兜底 + 计算）+ 资源（词典 / 参数 / 模板）。可单独交付，对应个人赛四赛道。
一道门
隐盾既是技能，也是所有技能进出模型的必经之门：本机脱敏、渐进授权、高危永远拦截、留痕不存原文。
换部门 = 换资源
资管部换产品报告模板、风控换制度库、子公司直接复制。

安全与合规：把合规做成产品特性

对照大赛红线：未脱敏客户信息、交易持仓、内部财务数据不得上公网大模型
三道防线由外到内，层层收窄
① 目录级授权只读指定文件夹；模型在内网
② 本机脱敏 / 还原客户 · 账号 · 金额 → 语义标签；映射表只在本机
③ 高危动作拦截外发 · 删除 · 改系统，永不放行

技能化架构：规范即合约，换部门只换资源

每项技能都是可单独交付的技能包 —— 也是个人赛四赛道的成果形态

规范Prompt / SKILL.md

  • 做什么、不做什么、输出格式（JSON 契约）
  • "分歧只摆不判"、"数字不得改动"写进规范
  • Agent 只在规范内发挥
  • 技能赛道：晨读要点抽取规范

代码规则兜底 + 计算

  • 段落归属、立场识别、否定语处理
  • 涨跌停 / 保证金 / 限仓 / 最后交易日计算器
  • 模型解析失败自动退回规则版
  • 工具赛道：隐盾脱敏小工具

资源换部门只换这一层

  • 品种词典 · 参数库 · 条款库
  • 周报 / 产品报告模板
  • 合规词表 · 事件日历
