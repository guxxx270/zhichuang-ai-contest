# 隐盾 · Demo 视频旁白稿（草稿 v2）

> 成片 4:19，1920×1080 · 30fps · H.264 + AAC，字幕已烧录（同名 .srt 另附）。旁白为合成语音（微软神经语音「晓晓」，edge-tts 合成），需要真人配音时按下表时间轴照念即可；演示数据全部虚构（yindun/samples.py）。
> 录制环境：本机启动隐盾 v0.2，Playwright 驱动本机 Chrome 按旁白时间轴自动操作页面，不调任何模型。「模拟回答」是手写的一段回答，故意改了几处标签写法，用来演示容错还原。重录方法见 `_制作工具/README.md`。
