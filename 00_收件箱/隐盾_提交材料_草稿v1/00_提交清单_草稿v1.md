## 二、这次直接改了的（隐盾 v0.1 → v0.2）

- **规则跟上需知 v0.6**：分段手机 / 身份证 / 银行卡、+86、座机、带上下文的 6～9 位短账号、机构泛称与动作词过滤、同事称谓不当客户、挨着号码的姓名。v0.1 是需知早期那份，这些漏洞当时还没补。
- **独立版新增**：技术凭据（私钥块、连接串口令、sk- / ghp_ / AKIA / LTAI / JWT / Bearer，只换值、留键名）；带单位的金额（万 / 亿要资金语境，单价、成交量不换）；同一号码不同写法算同一实体；标签按文中出现先后编号。
- **多轮会话**：v0.1 每点一次「脱敏」就重新从 `_1` 编号，第二轮会撞号、还原错位，README 里「多轮一致」实际不成立。现在同一会话共用映射表，旧实体沿用标签、新实体接着编号；映射表可导出、隔天载入。
- **容错还原**：v0.1 只认 `<客户_1>` 原样写法，模型一改写就还原不了。现在认 8 种写法（〈〉【】、Markdown 转义、HTML 实体、少下划线、去括号、全角），映射表里没有的标签单独提醒；一遍替换，不会二次替换。
- **网页**：原文对照标红、还原处高亮、疑似遗漏一键确认、类型开关、白名单、文件拖入（含 .docx）、「请原样保留标签」提示；三个虚构示例点一下直接脱敏（v0.1 的「试试示例」只填文字），配一段模拟回答演示还原。只在 127.0.0.1 监听，关闭使用统计。
- **命令行**：目录批量共用映射表、`check` 外发前检查（发现明文退出码 1）、剪贴板一键（`剪贴板脱敏.command` / `.bat`），映射表落盘权限 0600；新增 Windows 启动脚本。
- **测试与评测**：测试从 4 项增到 37 项（含网页 AppTest）；新增评测集与成绩单，另有一份规则定稿前就写好、提交到版本库（`defc48c`）的留出集。

## 四、需要你拍板的

1. **旁白是 macOS 合成语音（婷婷）。** 想换真人，按旁白稿的时间轴配音，再用 `_制作工具/video/assemble.py` 合成即可。
2. **PDF 用 LibreOffice 转出，字体换成了苹方。** 正式提交时建议在 Office 里打开 pptx / docx 另存一次 PDF，字体以微软雅黑为准；Word 打开时提示更新域点「是」，目录页码才会刷新。
3. **要不要把独立版的新规则同步回需知。** 需知 `xuzhi/privacy.py` 我没动（需知是团队作品，有 548 项测试，改它要整套回归）。现在独立版是需知那份的超集；技术文档里写的是「同源规则」。同步的话建议单独开一次，跑完需知全套测试再合入。
4. **评测集里有形似令牌的假数据**（`ghp_…`、`AKIA…`、`sk-…` 等，全部虚构、校验位也不对）。推送到 GitHub 时如果被 Secret scanning / Push protection 拦下，确认是测试数据后放行即可。
