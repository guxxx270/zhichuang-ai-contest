## 二、第一遍跑出来的问题（都已修）

| 现象 | 原因 | 修法 |
|---|---|---|
| 铁矿石被判「偏空」，光大原文结论是「震荡整理」 | 「需求端支撑有限……承压」这句压过了结论句，结论句里没有「预计」 | 结论句分级：策略 / 观点句 > 预计 / 短期句 > 段首短标题 > 普通句；「短期」「综合来看」「策略」「操作」都算结论标记 |
| 华泰铜判「偏多」但引的是「夜盘上涨 0.26%」这种行情句 | 同一品种多段（行情 / 现货 / 资讯 / 策略），取了第一段 | 同品种多段取结论强度最高、位置靠后的一段 → 现在引「操作上仍建议以逢低买入套保为主，买入区间 107400–107900」 |
| 光大铜判「偏空」，原文是「宏观压制与基本面利多同在，增加方向判断的难度」 | 词表没有这类中性表述 | 加「判断的难度 / 难以判断 / 多空交织 / 多空博弈 / 涨跌不一 / 等待 USDA」等中性词 |
| 原油多出一条南华「油脂偏强」 | 「油脂：……夜盘原油继续向上反弹」段里顺带提到原油 | 段落标题是板块词（油脂 / 钢材 / 煤焦 / 贵金属 / 铁合金 / 聚酯）时按板块别名归属，不按段内提及 |
| 玉米判「偏多」，原文「上涨乏力」 | 只处理了前置否定（限制反弹） | 加后置否定：乏力 / 有限 / 受限 / 不足 / 难度 / 放缓 |
| PTA 判「偏空」，引的是「产销：……整体回落」 | 「策略：」观点块没有边界，后面的「装置信息：」「产销：」也算进去了 | 「观点 / 策略 / 结论：」开启观点块，下一个「xx：」小标题结束 |
| 资讯稿里焦炭 / 焦煤 / 镍 / 碳酸锂全判「偏多」 | 首段「中证商品指数上涨」点名了一堆品种 | 无标题、点名 ≥4 个品种的综述段只取数据，不定立场 |
| 追问「看多铜的那家理由」返回苹果、红枣的句子 | 按单字重叠找句子 | 问题里有品种就只在该品种段落里找；有机构名（光大 / 华泰）就只在该机构材料里找；问「理由 / 为什么 / 怎么看」时优先结论句；按二字词重叠打分 |
| 长结论句被 80 字截断，把「预计短期焦煤盘面震荡运行」截没了 | 直接截前 80 字 | 只留结论所在分句（含前一分句） |
| 分歧雷达只认「多 vs 空」，铜的「华泰偏多 vs 光大中性」不算 | 口径太严 | 多 / 空 vs 中性也算「说法不一」，进雷达 |

## 三、评测集初版与跑分（mock 引擎，规则兜底）

- 立场标注 46 条（6 份材料 × 出现的品种，我按原文人工标的，标注理由在 csv 的 note 列）；追问 8 条（问题 + 期望来源机构 + 期望关键词）。
- **立场识别：严格准确率 42/46 = 91%；方向不反（多空不搞反）100%。** 4 处不一致都是「中性 vs 偏多 / 偏空 / 未明确」的边界：光大工业硅（无明确方向 → 未明确）、南华棉花（标题「外盘大幅回落」→ 偏空，观点其实是「交投一般」）、南华白糖（「上行难度加大」→ 我标中性、引擎判偏空，两可）、资讯稿燃料油（「宽幅震荡」段落里引了银河「航运指数震荡走高」）。
- **追问命中：8/8。**
- 这些数字可以先填进方案文档第 8 章「评测」的「初值」栏，口径写明「规则引擎、6 篇 46 条、人工标注」。接公司 AI 平台后用同一份金标准跑 llm 模式做对比，这就是答辩时「数字由程序算、模型只组织语言」的证据。
