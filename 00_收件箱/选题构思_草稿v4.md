# 选题构思 · 草稿 v4（"个人常用型"方向）

> 2026-09-07 ｜ Jerry 反馈：A"合同守门员"太专业，万一公司没有这类材料或拿不到就尴尬；希望是投资部 / 资管部 / 研究员**每天都用得上、提高工作效率**的 Agent。本版按这个口径重来。v3 保留在 git 历史。

## 0. 这版的选题原则

1. **只依赖三类材料**：公开研报（各家期货 / 券商官网可下载）、交易所公开公告与规则（上期所 / 大商所 / 郑商所 / 能源中心官网）、公司内部人人手里都有的文档（晨会纪要、周报模板）。**不依赖任何公司系统、合同、内部数据**——拿不到也不影响，拿到了锦上添花。
2. **"个人常用" = 每天打开、每次省时间**：成效用"每人每天省几分钟 × 人数"来算，评委一听就懂。
3. **贴"人人都有智能体"的题面**：Agent = 一个人 + 几项可复用的技能（Skills），技能本身可以拆去报个人赛。
4. 继续避开"观点打标签 / 涨跌 / 准确率回溯"。

## 1. 三个候选（同一方向，深度不同）

### 甲. 「投研伙伴」— 投资 / 资管 / 研究员的个人工作智能体（一个 Agent + 三项技能 + 一道安全门）★ 推荐

**故事线**："一个研究员的一天"。
- **8:30 早读**：昨夜到今晨的研报、交易所公告、宏观数据，按本人关注的品种做 5 分钟速读——每个品种一段：各家怎么说、**哪里有分歧**、关键数据变了什么、今天有什么事件（交割、限仓调整、数据发布、议息）。可追问"铜最近三家怎么看""公告原文在哪"。
- **10:00 百事通**：品种规则与制度的多跳问答 + 计算——"沪铜主力今天涨跌停板多少、保证金多少、最后交易日几号、我这个持仓量超没超限仓"。答案带出处（交易所规则条款 / 公告编号），计算过程可见。
- **16:00 写作**：周报 / 投委会材料 / 产品运作报告初稿——从模板 + 数据表 + 本周早读要点生成，图表自动画，合规自检（禁用表述、免责声明、数据引用），人工改定签发。
- **安全门（④）**：任何内容进模型前先脱敏（客户、账户、金额、内部代号），数据不出域，每次生成留痕。

**为什么它像"人人都有智能体"**：每个人的关注品种、模板、口径不同，Agent 记住个人偏好；技能是公共的、人是个性化的。

**Demo（现场可跑，全公开材料）**：现场下载当天 8–10 份公开研报和交易所公告 → 早读页 30 秒出"我的关注品种速读 + 分歧 + 今日事件" → 百事通页问三个规则问题（含一个计算）→ 写作页用模板生成一页周报草稿并标出两处合规提示 → 脱敏页演示一段含客户信息的文本进出。

**五维**：业务价值 5（每人每天省 60 分钟 × 研究员 + 投资经理人数）｜ 创新 4（个性化关注 + 分歧发现 + 规则计算 + 技能化架构）｜ 技术落地 4 ｜ 可复制 5（换部门换技能）｜ 安全合规 4 → **加权 89**

**风险**：大而全 → 演示要"两深一浅"（早读、百事通做深，写作做浅）；"分歧发现"只做"谁和谁说法不同"，**不做对错 / 准确率**，与作废的①划清界限。

**个人赛拆分**：早读技能 Prompt → 技能赛道；百事通规则库（自备 50 道问题）→ 知识库赛道；脱敏工具 → 工具赛道（Jerry）；整体构想 → 金点子。四个赛道全覆盖。

### 乙. 「投研早读官」— 只做"早读"这一件事，做深

同甲的早读技能，但把深度做足：多源（研报 / 公告 / 资讯 / 数据）→ 个人关注 → 分歧与变化 → 追问 → 一键转发给团队；再加"事件雷达"（未来两周与持仓相关的事件日历）。

**五维**：4 ｜ 4 ｜ 5 ｜ 5 ｜ 4 → **加权 88**。最"个人常用"，每天必用；单点做深不怕被说大而全；缺点是故事只有一幕，个人赛只能拆出技能 + 金点子。

### 丙. 「品种规则百事通」— 只做规则问答与计算

交易所规则 / 公告 / 公司制度 → 切片治理 → 检索 + Rerank → 带出处回答 + 计算器（保证金、涨跌停、交割日、限仓校验）。

**五维**：4 ｜ 3 ｜ 5 ｜ 5 ｜ 5 → **加权 87**。数据 100% 公开、最不怕拿不到材料、合规最稳、天然对应知识库赛道；缺点是创新性一般、"知识库"是热门题。

## 2. 我的建议

**团队赛选甲，Demo 按"早读深、百事通深、写作浅"做**——甲 = 乙 + 丙 + 一个轻量写作，故事完整、四个个人赛道全拆得出来；如果评审前发现时间不够，甲可以随时收缩成乙或丙而不推倒重来（代码是同一套技能架构）。

## 3. 从 Demo v0.1 复用什么

`llm.py` / `config.py` / `.env` 接入、`privacy.py`、PDF 读取、"文档 → 结构化卡片"的 Prompt + 规则兜底模式、SQLite 留痕、Streamlit 多页签——全部沿用；新增：多文档聚合与分歧检测、规则库检索、计算器、模板写作。
