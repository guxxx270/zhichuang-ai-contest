# 智创未来 AI 创新应用大赛 · 备赛仓库

> 国泰君安期货"智创未来"首届 AI 创新应用大赛（2026）备赛工作区。
> 导航、赛事要点、操作规则、决策记录都在 **[00_索引.md](00_索引.md)**，先看它。
> 本仓库为**私有**，只放自己的方案与文档；参考 PPT 的 PDF、他司材料、克隆的开源代码不入库（见 `.gitignore`），只版本化提要/摘要/评估。

## 怎么用这个仓库（一句话版）

- 文件夹在 Mac 上 `~/SynologyDrive/智创未来AI大赛/`，同时是 git 仓库。
- **Claude 负责 commit**：每完成一步（选题、方案、PPT、代码、Demo）就提交一次，里程碑打 tag，`00_索引.md` 第四节同步记决策。
- **Jerry 负责 push**：想同步到 GitHub 时双击 `推送到GitHub.command`（或让 Claude 双击）。第一次可能要在终端里登录一次 GitHub。
- 走错方向要回头：`git log --oneline` 找到那一步，`git checkout <commit> -- <文件>` 或 `git revert`，或者直接让 Claude "回到 xx 那一版"。
